# Security policy

The latest npm release and current `main` branch are maintained. Older versions
and commits are not maintained separately.

## Report a vulnerability

Use GitHub's **Report a vulnerability** option on the repository's Security
page when it is available. This keeps the report private while the maintainer
investigates it. If private reporting is unavailable, request a private
contact method from the repository owner without posting exploit details or
secrets in a public issue.

Include the affected version or commit, operating system, reproduction steps,
expected and actual behavior, and likely impact. Redact local paths and
credentials where possible. Please allow time for investigation before public
disclosure; no fixed response or remediation deadline is promised.

The finder reads local skill metadata and MCP configuration. Reports about
untrusted paths, activation, CLI installation, and MCP request handling are
especially useful.
